
COMPREHENSIVE FLUTTER APP BUILD PROMPT — "event." Event Discovery Platform
🎯 PROJECT OVERVIEW
Build a premium, luxury-grade event discovery and ticket booking application called "event." using Flutter. The app is inspired by the Fever event platform. It must run on Android, iOS, and Web with a fully responsive layout. The design follows a dark luxury theme with deep teal/dark green backgrounds, golden/amber accents, and rich atmospheric imagery. Every screen, every component, every spacing, every shadow, every animation, and every micro-interaction described below must be implemented exactly as specified. The language is English, the layout direction is LTR (left-to-right), and the currency is British Pounds (£).
